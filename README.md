# IPL-analysis-using-power-bi
🏏 IPL Power BI Dashboard

An interactive IPL Power BI Dashboard designed to analyze and visualize Indian Premier League data. The dashboard provides insights into team performance, player statistics, match results, batting and bowling performance, and overall IPL trends.

📊 Dashboard Features

* 🏆 Team-wise performance analysis
* 🏏 Player batting and bowling statistics
* 📈 Runs, wickets, 
* 🎯 Match wins and losses by team
* 🗓️ Season-wise IPL performance
* 🔍 Interactive filters and slicers
* 📌 KPI cards for important statistics
* 📊 Interactive charts and visualizations

🛠️ Tools & Technologies

* Power BI
* Power Query – Data cleaning and transformation
* DAX – Calculated measures and KPIs
* Excel/CSV – Data source

🎯 Objective

The main objective of this project is to transform IPL match data into an interactive business intelligence dashboard that makes it easier to understand team and player performance and identify meaningful trends and patterns.

📁 Project Contents

* IPL Power BI Dashboard.pbix – Power BI dashboard file
* Dataset/ – IPL dataset
* Screenshots/ – Dashboard screenshots

🚀 Key Learning

This project helped me strengthen my skills in data cleaning, data modeling, DAX, data visualization, and Power BI dashboard development.
